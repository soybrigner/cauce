# Cauce

Registra por dónde entra y sale tu dinero, repártelo en cuentas y alcanza tus metas con calma.

Es una app instalable (PWA): se abre desde el navegador, se puede agregar a la pantalla de inicio y funciona sin internet. Tus datos se guardan solo en el navegador del dispositivo; usa «Guardar una copia» en Ajustes para respaldarlos.
