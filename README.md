# Cauce

Registra por dónde entra y sale tu dinero, repártelo en cuentas y alcanza tus metas con calma.

Es una app instalable (PWA): se abre desde el navegador, se puede agregar a la pantalla de inicio y funciona sin internet.

- **Sin cuenta:** tus datos se guardan solo en el navegador del dispositivo. Usa «Guardar una copia» en Ajustes para respaldarlos.
- **Con cuenta (Firebase):** llena `firebase-config.js` con los datos de tu proyecto de Firebase y publica las reglas de `firestore.rules`. Entonces Cauce ofrece entrar con correo y guarda una copia privada que ves en todos tus dispositivos.
